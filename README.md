# 虾米对练场

八款原创浏览器小游戏，探索可交互玩法、规则对手与可选的大模型对手。

**[进入试玩](https://cherler.github.io/xiamimate-game-agent-lab/)**

在线展示版的八款游戏都在浏览器中运行，不需要登录。进度与纪录保存在当前浏览器，支持导入、导出对局回放。赛车、音游和跑酷保存本地最好成绩，进行中的比赛在页面内切换时暂停，刷新页面会重新开始。它们仍处于玩法验证阶段，欢迎反馈操作体验与难度。

微光救援需要主动呼叫接驳，三关分别守住 16／18／20 秒，可用共享补给投放诱饵或范围急救；敌人逼近或护卫离开会暂停读秒。旧版行动仍按旧规则恢复，可点击“体验战术救援版”重新部署。

## 进度存在哪里

在线单人进度保存在当前浏览器的本地存储，不是所有玩家共享一局。相同网站、相同浏览器个人资料会读取已有存档；换浏览器、换设备或使用无痕窗口会获得独立的新进度。清除网站数据也会清除存档，目前没有账号或云同步。同一浏览器的多个标签页共用存储，建议同一款游戏只开一个游玩标签。

贪吃蛇、乒乓、牌局、棋阵和救援支持恢复已有局面；赛车、音游与跑酷保存纪录，页面内切换暂停，刷新则重新开局。导出录像可留作重看，录像导入不等于全量进度迁移。

## 本地运行

线上只提供当前试玩版本，历史改动保留在 Git 源码分支和提交中。原有浏览器存档及回放兼容逻辑继续保留；下线历史页面不会清除玩家存档。

需要 Node.js 22 或以上。

```sh
npm ci
npm test
npm run build
npm start
```

打开终端打印的地址，默认是 `http://127.0.0.1:4841`。

Mac 上也可双击 `启动对练场.command`，预览会在后台持续运行；`停止对练场.command` 用于停止。`离线试玩.command` 或直接打开构建后的 `dist/index.html`，无需启动服务即可试玩八款单人游戏。

## 静态部署

```sh
npm run build:pages
```

发布 `site/` 目录即可。全部画面、样式和游戏逻辑打包在单个 HTML 内，不依赖外部素材地址，支持 GitHub Pages 的仓库子路径。

本仓库使用 `gh-pages` 分支根目录发布。发布页和源码分开维护，源代码在 `main`；提交源代码本身不会自动更新试玩页。维护者提交并推送源码后，运行 `npm run deploy:pages` 即可生成并推送新的试玩版本。备用的 Actions 模板位于 [docs/examples/pages-workflow.yml](docs/examples/pages-workflow.yml)。

`deploy:pages` 仅允许在 `main` 使用，每次只发布 `.nojekyll`、`index.html` 与 `release.json`，移除历史试玩、试验版和对照页面。历史源码保留在各开发分支；需要恢复某次改动时，从对应分支或提交恢复源码后重新构建发布。`rollback:pages` 默认只预览，加 `--apply` 才替换当前入口，且不会恢复旧版页面目录。

## 可选模型与好友房

在线展示版提供浏览器内的规则／寻路对手。Laya、Jev 等模型需要独立推理服务或接口；卡牌好友房需要本地房间服务，不能由静态网页直接提供。

本地服务支持通过环境变量配置 `LAYA_BASE_URL`、`ARENA_PYTHON` 与 `TYPESAFE_API_KEY`。请将密钥放在本地 `.env`，不要写进前端或上传仓库。本地模型依赖在 `python/requirements.txt`；权重、运行目录和环境文件不包含在此仓库内。

`启动好友局.command` 提供局域网卡牌房间入口。房间状态保存在服务端内存，服务重启后清空；当前不提供公网账号、匹配大厅或永久云存档。

## 验证与结构

`src/` 是游戏规则，`web/` 是界面与绘制，`test/` 是规则与回放检查，`scripts/` 提供构建、对战验证和浏览器验收。

```sh
npm test
npm run bench:rescue
npm run check:extraction
npm run check:polish
npm run check:chess-screen
npm run check:chess-phase
npm run check:motion
npm run check:kart-motion
npm run check:runner-routes
npm run check:runner-rush
npm run check:runner-stride
npm run check:runner-depth
```

浏览器验收需要先启动预览，并安装 Playwright 与 Chromium；也可用 `ARENA_PLAYWRIGHT` 指向现有安装的 `index.mjs`。`ARENA_URL` 可更改测试地址，`ARENA_RESULTS` 可指定结果目录。
