# 微光游戏免费试玩托管方案

核查日期：2026-11-18。

## 建议

可以用 **GitHub 公开仓库保存源码，GitHub Pages 提供五款游戏的单人试玩**，不需要为这部分继续租常驻服务器。当前游戏的画面、操作、规则对手、存档和回放均可在访客浏览器里执行；打包后的完整页面约 0.514 MB。

GitHub Free 支持公开仓库的 Pages；Pages 托管 HTML、CSS、JavaScript，也支持自定义域名。这与目前的展示用途相符。[GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

建议先使用平台提供的试玩地址，实际测试你和朋友所在网络的访问体验，再考虑绑定 `games.xiamimate.com`。该子域名只是建议，目前没有修改域名解析或发布线上站点。平台免费额度不能保证所有地区、运营商的打开速度，需以目标用户的实测为准。

| 双蛇争食：规则与寻路对手 | 可用 | 不需要 |

Pages 不执行当前的 Node 房间服务和 Python 本地模型。大模型的调用费用、额度、服务端密钥管理也不会因为代码开源而消失。首版先让规则对手完整可玩；后续若加入模型对手，再把模型代理作为独立可选服务接入，保留规则接手。

开源代码与提供试玩是两件事：试玩只需公开构建产物，正式开源还应由项目所有者选定许可证；本轮没有代替你授予代码许可证。

## 平台取舍

| 方案 | 对当前项目的意义 | 限制 |
| --- | --- | --- |
| **GitHub Pages，首选** | 源码、版本和试玩在同一平台，适合公开项目展示 | 免费方案使用公开仓库；没有常驻后端 |
| **Cloudflare Pages，备选** | 同一份 `site/` 文件可直接迁移，后续能另接 Functions | 后端函数有独立额度，不能把本地 Python 模型直接搬过去 |
| 阿里云现有服务器 | 可保留原有服务及需要常驻进程的功能 | 仍有每月租用费用 |

GitHub Pages 当前发布站点上限为 1 GB，月带宽软限制为 100 GB；当前小游戏的体积远低于站点上限。其用途限制不支持把 Pages 当作商业交易或商业 SaaS 的免费托管服务，未来若转为这类运营形态，需要重新评估。[Pages 限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

Cloudflare Pages 的静态资源请求免费且不限请求数；Functions 与 Workers Free 共用每天 100,000 次请求额度。免费版每月 500 次构建、最多 20,000 个站点文件、单个文件最大 25 MiB，这份小游戏页面也在范围内。[静态资源与函数计费](https://developers.cloudflare.com/pages/functions/pricing/) · [Pages 配额](https://developers.cloudflare.com/pages/platform/limits/)

## 已准备好的部署内容

- `npm run build:pages` 生成 `site/index.html` 和 `site/.nojekyll`。
- 页面内含全部样式、逻辑和原创矢量绘制，可部署在仓库子路径，五款游戏均不依赖外部素材地址。
- 静态版不会请求本机的 `/api/providers`、模型或房间接口；没有后台服务时，相关选择不可用。
- `.github/workflows/pages.yml` 已准备好，手动运行后依次安装依赖、运行规则检查、构建并发布 **仅 `site/`**。
- 本地已用模拟的 `/demo/` 子路径验收；尚未在真实 GitHub 仓库运行发布工作流。

发布时，将这个游戏项目作为独立仓库的根目录。首次在仓库的 Settings → Pages 中选择 GitHub Actions，再在 Actions → Publish playable demo 中手动运行。仓库页面地址通常形如 `https://账号.github.io/仓库名/`，实际地址以发布结果为准。本轮工作流没有自动推送触发。[GitHub 自定义 Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

本地模型权重、运行目录和环境配置已排除在常规版本跟踪之外。发布的网页只来自 `site/`，不包含这些服务端文件。

## xiamimate.com 的费用能否一起省掉

**小游戏采用免费托管，不会自动取消现有阿里云费用。** 如果主站同样只有作品页、图片和前端交互，也可以评估整体迁移；如果主站还有登录、数据库、上传或其他接口，则需要逐项处理这些服务。

本轮没有审计或修改现有主站、阿里云配置、域名记录。建议先独立上线游戏并验证访问体验，再盘点主站依赖、确认迁移完成，最后决定是否停用阿里云。继续使用 `xiamimate.com` 时，域名本身仍需续费；平台提供的默认域名则无需购买自己的域名。
