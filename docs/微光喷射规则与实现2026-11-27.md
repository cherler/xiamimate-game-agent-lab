# 微光喷射：规则核实与第一版实现

2026-11-27。入口 `#ink`，源码分支 `gameplay/ink-turf-2026-11-27`。

## 核实的对标规则

任天堂将《斯普拉遁》的核心模式称为 Turf War，占地对战：两队各四人，三分钟，以结束时的涂地面积判断胜负。击倒对手能争取涂地时间，击倒数不是胜负条件。来源：[任天堂占地模式介绍](https://play.nintendo.com/news-tips/tips-tricks/splatoon-3-tips-and-tricks/)。

角色可以在未涂墨地面行走；己方墨水用于潜行、快速移动和补墨，敌方墨水妨碍移动。被击倒后会重新加入战斗，并非只要接触敌方颜色便立即死亡。来源：[任天堂玩法介绍](https://splatoon.nintendo.com/en/gameplay/)、[任天堂 Splatoon 101](https://www.nintendo.com/en-gb/News/2017/July/Dive-into-Splatoon-2-with-our-Splatoon-101-1245215.html)。

覆盖敌方墨水同时扩张己方占地、缩小敌方占地；出生区域也值得涂满。来源：[任天堂联网模式指南](https://splatoon.nintendo.com/en/news/beginner-basics-for-splatoon-3-the-ins-and-outs-of-playing-online/)。

## 第一版落地

| 部分 | 微光喷射的实现 |
| --- | --- |
| 队伍 | 玩家加三名规则 AI 队友，对抗四名规则 AI。无服务器依赖。 |
| 目标 | 180 秒。双方颜色覆盖可以互相替换；障碍物不计面积，未涂地面计入总面积。相同面积明确判平局。 |
| 场景 | 彩潮码头、回环广场，两张对称的俯视地图；掩体阻挡人物、射击和涂色，侧路可绕行。 |
| 形象 | 原创彩色小球、枪口、玩家外环和指示尖角；墨迹、弹丸、命中环与击倒飞溅直接反馈战斗。 |
| 武器 | 一种连续喷射器，有限射程与墨量，持续喷射同时涂地和造成命中伤害。友军不受伤。 |
| 补给 | 己方墨水内按住潜行，游动加速、墨量快速恢复；停止射击也能慢速补墨。 |
| 敌墨 | 可以经过，明显减速并造成有限持续伤害；地面伤害不会单独击倒角色。 |
| 重生 | 连续命中击倒，四秒后回到己方出生区，短暂护盾；主动开火会结束护盾。 |
| AI | 同样使用墨量、射程、碰撞、重生规则；选择可涂区域、绕过障碍、与敌人交火、退回己墨补给。潜行远处目标不会被 AI 直接锁定。 |
| 操作 | 电脑 WASD／方向键移动，鼠标按住喷射，Shift／空格潜行。手机左摇杆移动、右摇杆拖动瞄准并射击、潜行按钮。 |
| 手机 | 竖屏将地图纵向展示；横屏使用横向地图；浏览器不支持方向锁定时可用“横屏玩”旋转网页和输入坐标。 |
| 界面 | 主画面显示占比、倒计时、生命／墨量、短暂状态；地图、对手档位、回放、音乐放在设置里。 |
| 音乐 | 复用项目已有 CC0 曲目 Raspberry Jam 与公共音量设置，增加喷射／击倒音效。 |
| 续玩 | 当前浏览器独立保存；离开游戏、打开设置或切后台时暂停；刷新恢复暂停中的进度。支持导出、校验和重播 `ink-1`。 |

移动速度、墨耗、26 点单发伤害、100 点生命、四秒重生等为本作第一版参数，不是任天堂原作数值的复刻。第一版实现平面涂地、交火与补给循环；武器组、爬墙、高低差、超级跳跃、大招和真人联网尚未加入。

视觉采用深蓝场外、灰绿地面、青绿／珊瑚两队墨水、奶白玩家标记。小球与枪口沿用救援的辨识方式；战场居中，资源与操作尽量放在空隙，保留地图本身为主要画面。

## 验证

- `npm test`：255 项通过，包括新增九项喷射规则、AI、坐标转换和确定性回放测试。
- `npm run check:ink`：电脑移动／喷射／潜行，暂停，地图切换，刷新续玩，九款切换，回放结束和三分钟胜负结算。
- 独立 Chromium 模拟 390×844、844×390、320×568、667×375 的手机画面及多指输入：同时移动与射击、抬手停止、潜行、触控取消、网页旋转坐标和设置暂停。
- 两张地图各十二局完整 AI 对战：码头双方胜场 6:6，广场 4:8。没有替代真人试玩；样本不足以确认长期平衡。
- 使用项目已有本机浏览器运行环境；未连接实体手机或真人网络对战，真机性能及长时间手感仍需用户反馈。

可重复检查的脚本为 `scripts/check-ink-browser.mjs`，单元测试为 `test/ink.test.mjs`。本地截图、测试输出和模拟记录在不发布的 `.runtime/ink-turf/`。
