# 微光救援：撤离坚守

日期：2026-11-18。规则版本：`rescue-3`。

针对“平民到达撤离点立即结束，缺少防守过程”的反馈，这次将流程改为：接应平民、撤离区集结、抵挡尸潮并守住读秒、完成接驳。三个小队、自动射击、暂停指挥、门障、关卡升级仍沿用原有操作。

## 新规则

| 关卡 | 读秒 | 信号引来的额外丧尸 | 完成条件 |
| --- | --- | --- | --- |
| 走廊接应 | 16 秒 | 6 只，含 1 只快速丧尸 | 至少撤离 8／10 人 |
| 双门夹击 | 18 秒 | 10 只，含 2 只快速丧尸 | 至少撤离 12／15 人 |
| 分区清剿 | 20 秒 | 8 只，含 2 只快速丧尸 | 至少撤离 16／20 人，并清除全部常规与额外尸群 |

首次有平民进入撤离区便呼叫接驳，额外尸潮在 3 秒预警后入场，原有波次仍会继续。信号期间丧尸移动加快 30%，攻击伤害提高约 30%，攻击间隔从 0.8 秒缩短为 0.6 秒；狂暴持续“预警＋本关读秒＋10 秒”。第三关原有波次最多，因此额外尸潮数量不按关卡机械递增。

平民进入撤离区后会向后方聚集，仍可被感染。至少一名存活队员留在区内，且附近没有能直接威胁撤离区的丧尸时，接驳进度才增加。护卫离开或敌人逼近只暂停进度，不会重置。读秒完成后，当前集结的平民整批撤离；后续另有平民抵达则会开启新一轮接驳和尸潮。战术暂停同时冻结全部游戏时间。

第一关撤离区增加隔墙与可设障的门口，让护卫前排、步枪后排、平民后方集结形成可守的阵地。门障可以延缓尸群并争取读秒。到达关卡总时限时，未完成撤离／清剿会失败，不能仅通过等待或清空当前一波绕过撤离目标。

## 画面反馈

- 地图上方常驻圆形倒计时、进度条、集结人数和当前状态。
- 地图撤离区同步显示剩余时间；受威胁时变为“读秒暂停”。
- 尸潮预警显示剩余秒数和入口；狂暴时丧尸变为橙红色，带外圈和箭头。
- 缺少护卫、敌人逼近分别显示暂停原因；排队的平民带绿色外圈，尚未计入已撤离。
- 旧存档显示“历史行动”，提供“体验撤离坚守版”按钮；原记录保持旧规则。

## 验证结果

90 项规则检查通过，包含新增的集结、完整读秒、护卫条件、威胁中断、感染、狂暴移动、超时条件和三份旧版完整回放校验。

救援浏览器流程 7 组、撤离专项流程 5 组通过，页面异常为零。检查覆盖桌面和 390×844 触控窗口、真实指令产生的读秒／失守局面、三关结算与升级、刷新续接、回放导入导出、旧存档切换新版、离线单文件。手机结果来自浏览器模拟，不代表所有真实手机的性能。

### 90 场固定方案对照

每关、每种方案各运行 10 个种子，种子改变刷怪位置偏移，不改变地图。

| 方案 | 第一关 | 第二关 | 第三关 |
| --- | --- | --- | --- |
| 不操作 | 0／10 胜 | 0／10 胜 | 0／10 胜 |
| 集中防守，不带平民撤离 | 0／10 胜 | 0／10 胜 | 0／10 胜 |
| 接应、回撤、门障掩护，第三关继续清剿 | 10／10 胜，撤离 10 人 | 10／10 胜，撤离 15 人 | 10／10 胜，撤离 20 人 |

通关方案在第二关使用火力升级，第三关使用火力＋门障升级。第三关先守完接驳和狂暴期，再向中央南侧推进。种子 41003 下，三关用时约 34.4、30.7、112.9 秒。

这些结果用于确认有可重复的通关路线，以及不撤离方案不能绕过目标，不是玩家胜率或全面平衡结论。第二关提前布置门障能让尸群绕行，熟悉路线后压力明显下降；第三关时限仍较紧，移动升级组合的容错低于门障或双火力，后续可根据实际试玩继续调整。

## 兼容、复现与发布

`rescue-1` 和 `rescue-2` 回放继续使用原地图、原波次、原结算逻辑；升级不会静默改写旧行动。新版导出为 `rescue-3`。

```sh
npm test
npm run build
npm run preview:background
npm run bench:rescue
npm run check:rescue
npm run check:extraction
```

浏览器验收依赖 Playwright 和 Chromium；可通过 `ARENA_URL`、`ARENA_RESULTS` 和 `ARENA_PLAYWRIGHT` 更改测试地址、输出位置和已有安装入口。本轮本机证据位于工作区 `output/game-agent-lab/rescue-extraction-2026-11-18/`，不随公开源码上传。

试玩通过 [GitHub Pages](https://cherler.github.io/xiamimate-game-agent-lab/#rescue) 发布，方法见 [发布记录](GitHubPages发布.md)。线上实际版本以 [release.json](https://cherler.github.io/xiamimate-game-agent-lab/release.json) 为准。
