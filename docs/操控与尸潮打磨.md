# 操控与尸潮打磨

日期：2026-11-19。源码分支：`gameplay/controls-horde-2026-11-19`。

## 本轮改动

**乒乓球**：球拍从每帧最多 8 单位提高到 14 单位，提升 75%；目标位置由每 6 帧更新改为逐帧更新。按键松开立即停止追赶旧目标，减少松手后的滑动。球速、拍面大小和三档 AI 的判断间隔不变。鼠标、触屏、四个朝向共用同一套移动规则。

**微光棋阵**：拖起己方棋子，底部操作区临时变成“备战席 / 出售”两个落点，棋盘和备战席不移动。出售前显示实际返还金币，装备仍返还背包。可以拖回真实备战席，也可以拖到操作区的备战席落点。满席拒绝退回，误拖到棋盘外、按 Escape、取消触摸或切走窗口不会出售。点击布阵、查看详情和原按钮继续可用。

**微光救援**：点击队员选单兵；Shift 点击增减选中队员；地面拖框多选；双击队员选同组。小队按钮与 1／2／3／4 可切换两组步枪、护卫、全队。点地面或右键下达移动命令，拖动已选队员也能给当前选中的队员一起下令。选中圈、人数、路径、成功/失败落点反馈同时显示。触屏支持小队按钮、点地面、拖兵下令及框选；放大后空地拖动仍用于移图，点“框选”可切到选择工具。暂停时可以继续下令。

## 对标调研与取舍

已核对 [Zombies Aren’t Real 官方商店说明](https://store.steampowered.com/app/5185890/Zombies_Arent_Real/)：核心是俯视城市、提前部署有限兵力、设置安全区/门、在感染扩散时调动战术支援。官方说明支持“先部署，再根据战况调整计划”的节奏，并列出狙击、炮兵、驻军、空袭等能力。

开发者的 [v0.43.1 更新公告](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/1849458702689544) 进一步改善平民绕障、自动进入安全区以及救护运输的自动行为。这给本轮的启发是：减少重复操作，让玩家把注意力放在布防与接应上。

本轮框选、Shift 多选、数字切队、右键移动是针对微光救援现有可移动小队的设计决定；官方文字没有确认原作采用这套按键，不能当成原作操作表。官方实机 HLS 在本次环境读取超时，没有把该片段计作已观看。现有自动射击、自动接应、战术暂停与补给继续承担简化操作的作用。

## 验证

- `npm test`：165 项通过，含旧乒乓录像、救援 v1–v4 兼容及新版完整回放。
- `npm run check:controls`：桌面鼠标与真实触摸事件覆盖拖放出售、装备返还、满席、取消、框选、Shift 多选、数字切队、拖兵下令、不可达位置、放大移图和刷新恢复。
- `npm run check:chess-screen`：320–1920 像素、横屏和矮屏下，棋盘、备战席和操作区同屏；买卖、部署、装备、跨轮和旧存档恢复有效。
- `npm run check:rescue`：三关结算、升级、手机下令、暂停恢复、录像导入导出和离线单文件通过。
- `npm run check:round3`：四向乒乓、鼠标/触屏坐标和棋阵流程回归检查。
- `npm run bench:rescue`：3 关 × 3 种策略 × 10 个种子，共 90 局。正确护送 30/30 通关且全员撤离；挂机与只守固定位置 0/60 通关。这验证可行性和基本压力，不代表所有人类打法的胜率。
- 100 只同时在场的模拟压力检查：120 次步进平均 2.01 ms、P95 3.03 ms。本机 Node 模拟耗时，不等同于手机画面帧率。

检查产物保存在仓库旁 `output/game-agent-lab/controls-horde-2026-11-19/`，不发布到试玩网站。旧检查脚本的游戏数量和存档注入时机也已更新。
