# 微光疾行：阿米与城市路线

日期：2026-11-19。分支：`gameplay/runner-courier-routes-2026-11-19`。

## 角色

主角改为原创的“虾米快递员阿米”：圆虾壳、触须、卷尾、小背包和短靴。欢迎画面是正面笑脸，跑动时显示背面邮包；跳跃收腿、翻滚蜷成一团，护板与磁铁仍有独立效果。角色继续使用浏览器内的矢量绘制，不需要外部素材加载。

画面采用珊瑚橙角色、薄荷绿邮包、浅蓝水面和暖黄色奖励；金币收集显示短暂的加分反馈，动作位置在显示帧之间平滑过渡。

## 路线与取舍

| 路段 | 场景与主要节奏 |
| --- | --- |
| 0–400 米：晨光车站 | 站台、路灯和车厢；先认清三条路线，再加入换道、跳跃与下滑 |
| 400–800 米：桥下市集 | 布篷摊位和暖色路面；连续换道，配合路障与低横梁 |
| 800–1,200 米：滨河栈桥 | 木板、水面、帆船和缺口；判断跳跃奖励与安全绕行 |

之后循环进入新的城区段。路线每段八组，连续动作之间安排两处喘息区，段尾有道具及较长间隔；后续城区会镜像、重排动作组合。道路有缓弯，玩家仍使用三道换位操作。

普通金币引导无障碍路线；星星放在需要跳跃或下滑的位置，每颗计两枚金币。玩家可以选择安全绕行，也可以挑战额外奖励。每组都保留一条无障碍路线，障碍上用向上、向下箭头区分操作。

列车碰撞现在包含车身后半段，避免车头经过后能穿过车身的情况。护板仍抵挡一次碰撞，磁铁仍吸引附近金币。难度通过速度提升体现，首轮城区顺序固定，便于认识规则。

这一轮包含地面三道、缓弯、城区更替、奖励路线和动作编排；尚未增加上车顶、坡道、分岔选关或快递任务系统。

## 存档与录像

新对局使用 `runner-2`。原来的 `runner-1` 规则完整保留，旧录像仍按原来的障碍、速度和计分播放。旧版最好成绩保留，新路线使用独立的成绩记录，避免把不同奖励密度的成绩混在一起。

“重新出发”进入新路线。键盘、四向滑动、双击护板、按钮与页面内暂停继续均保留。

## 后续打磨：速度与碰撞（同日）

分支：`gameplay/runner-rush-impact-2026-11-19`。用户反馈默认节奏太慢，撞上障碍缺乏冲击，因而这一轮保留阿米和三城区，重点调整速度、动作响应及碰撞呈现。

| 项目 | 调整前 | 本轮 |
| --- | --- | --- |
| 默认难度 | 舒缓起跑 | 疾速奔跑；可切换练习慢速 |
| 默认起速 / 最高速 | 16 / 27 | 34 / 52 |
| 默认加速度 | 0.095 | 0.42 |
| 练习档起速 / 最高速 | 16 / 27 | 24 / 38 |
| 单道换位时间 | 约 143 毫秒 | 约 91 毫秒 |
| 跳跃 / 翻滚时间 | 0.96 / 0.72 秒 | 0.78 / 0.58 秒 |
| 首次必须躲避 | 起跑数秒后 | 起跑约 1.6 秒；倒计时已可看见障碍 |
| 致命碰撞 | 立即盖住画面结算 | 先展示约 0.88 秒的撞击或坠落再结算 |

速度数值是游戏内单位，不等于现实中的千米/小时。每组仍保留安全路线；原有每段两处喘息区、星星奖励、磁铁和护板继续保留，分布整体前移 24 米，第一组中间车道出现列车，引导第一次换道。

镜头轻微跟随换道，道路延伸至屏幕底部，路边流动线和脚下尘迹增强接近感；同车道近处的危险用暖色接触线标出。撞到车或路障时身体压缩后仰、出现冲击星点；坠落会缩小并沉入缺口。护板破碎产生碎片并短暂停顿 65 毫秒，然后继续跑。碰撞一刻即锁定结果，展示动画不再推进得分或接受脱险操作。

声音开关开启后才播放风声、跳跃、翻滚、碰撞闷响及碎裂声。暂停、切换游戏、隐藏页面和静音会停止风声。减少动态效果设置关闭镜头震动、闪色、速度线及跑动抖动，保留碰撞原因和结算。触感反馈仅在浏览器支持且非回放时调用，不能保证所有手机均有震动。

新对局格式为 `runner-3`；`runner-v2.mjs` 完整保存调整前规则，`runner-1` 和 `runner-2` 均按各自旧规则回放。新成绩单独保存为 `runner3-best-*`，不覆盖前两代成绩。

验证包括 150 项规则检查；两档难度各六组种子沿安全路线跑到 5,000 米，达到最高速度仍可通过，并可精确重放。起速与最高速下，跳跃/翻滚均能通过对应障碍并拿齐星星。浏览器检查覆盖四种碰撞、护板停顿后继续、静音与暂停、旧录像、五种疾行布局，以及赛车/音游等 18 种布局回归。验证工具模拟触摸事件，尚不代表每种实体手机的性能或触感。

## 后续打磨：跑道可读性、六景与步态（同日）

分支：`gameplay/runner-lanes-worlds-stride-2026-11-19`。用户反馈跑道分隔不清、近景遮挡导致误撞，人物动作像原地抖动。这一轮保持原有疾速与碰撞规则，修改视觉、动作及风景选择。

### 视野

三条跑道采用不同明度的铺装和深浅双线分隔，削弱横向地面纹理。换道不再拖动整个镜头；角色鞋底、投影和位置标记使用同一个地面坐标。邻道接近镜头的大型障碍渐变为约 34% 不透明度，同时保留接触边线与操作图标；自身碰撞车道上的障碍保持实心，轻型路障不淡化。路边树冠、摊位等在跑道之前绘制，不会盖住可行走区域。近处障碍的换道、跳跃、下滑图标最后绘制，避免被前景盖住。

### 六种风景

起点可选晨光车站、桥下市集、滨河栈桥、雨林遗迹、落日峡谷、雪山驿道。每 400 米切换，2,400 米后循环。每种风景有各自道路材料、远景和路边物件；大型障碍分别表现为列车、货车、货箱、巨石、岩柱、雪车。巨石和岩柱同样必须换道，提示使用 ↔，结算说明随外观变化。

风景属于表现层，不改变障碍的时间、位置、速度和奖励。录像在 `options.scenery` 记录起点，缺省时使用车站；旧格式和旧成绩继续可用。

### 跑步动作

步态由行进距离驱动，避免“时间乘不断变化的速度”造成步频跳变。每条腿有髋、膝、踝与鞋底：支撑阶段脚贴地并向后蹬，回收阶段屈膝抬脚，左右交替，步间保留短暂的双脚腾空。骨盆随支撑下压并在腾空时抬起，手臂与前伸腿反向摆动。背包、尾部轮廓和触角保留阿米的特征，背包与触角加入滞后摆动。

跳跃时收腿，落地约 160 毫秒屈膝缓冲；换道后约 220 毫秒恢复直立。翻滚时壳纹和邮包绕身体前滚。脚步、落地声只在全局声音开启时播放。减少动态效果设置停用周期性步态和附属摆动，仍保留输入动作与碰撞说明。

参考入口：[Subway Surfers 官方展示](https://subwaysurfers.com/)、[Temple Run 2 官方展示与截图](https://imangistudios.com/thegames/temple-run-2/)。官方 YouTube 演示在当前环境返回配置或内容不可用；未将其视为已完整观看的逐帧证据。实际核对了官网截图的轮廓与路径表现，阿米的关节步态由本项目自制，没有导入商业游戏动画或角色素材。
