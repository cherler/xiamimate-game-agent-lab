# 第三轮改进与验证

2026 年 11 月 17 日。试玩入口：[虾米对练场](http://127.0.0.1:4841/)。已经打开的页面需要刷新，才能加载本轮界面与规则。

## 四款游戏的变化

| 游戏 | 当前行为 |
| --- | --- |
| 球台对攻 | 默认玩家球拍在下方，通过左右拖动或左右键控制；可选择四个方位或每次旋转 90 度。旋转不重开比赛，键盘、鼠标和触控随方位映射，选择自动保存 |
| 双蛇争食 | 保持原玩法与速度，吃食物增加光圈、碎点、加分与分数跳动；允许预输入两个连续转角，过滤反向输入；回放也展示吃食物效果 |
| 微光棋阵 | 8×8 棋盘、你与 7 位规则 AI、24 种原创棋子、5 格商店、8 格备战席、共享棋池、三合一升星、利息和连胜连败收益、经验与人口、羁绊、野怪与装备、玩家配对、淘汰名次；支持点击和拖动布阵、观察对手、快进、保存恢复及动作回放 |
| 微光牌局 | 默认练习档，另有标准与挑战；后手额外获得临时能量牌，补强工坊和林地萌芽，重新配置星塔霜息的反击手段；保留卡牌出场、法术来源与命中顺序 |

棋阵参考 [Dota Auto Chess 官方作品](https://steamcommunity.com/sharedfiles/filedetails/?id=1613886175) 的棋盘与自走棋核心循环，采用本项目原创角色与规则数值。当前是单人八人联赛；新界面已移除好友房和模型选择，七位对手使用不同经济倾向的规则 AI。旧的二人棋阵逻辑仅用于历史回放与兼容，不等于实现了八人在线联机。

棋阵准备阶段由玩家主动开战，不设抢操作倒计时。前 3 轮为野怪，随后进入棋手对战，第 10 轮及之后每 5 轮再出现野怪。每存 10 金增加 1 金利息，最多 5 金；同名棋子不会重复贡献羁绊。满备战席时能即时合成的购买仍可完成，不能合成则整笔购买失败而不扣钱。淘汰者的棋子和商店预留返回共享池。

## 牌局的具体调整

- 练习档使用较短的判断，并在接近的合法选择中保留变化；标准档选一步内最佳动作；挑战档继续使用原来的两步评估。三档使用相同卡牌和资源规则。
- 后手仍多一张起手牌；换牌结束后，在后手第一次行动时额外获得“余光水晶”：0 费，本回合临时获得 1 点能量，总量不超过 8。它只发放一次，不能参与起手换牌。临时能量用金色水晶区分。
- 铜壳卫兵从 2／2 改为 2／3，弹簧突击者从 4／3 改为 4／4，改善工坊重装的站场与交换。
- 林径疾鹿从 3／4 改为 4／4，帮助林地萌芽在中期处理对手的 4 生命单位。
- 破晓彗星的主目标伤害从 6 改为 7，溅射仍为 2，使未强化的古树守望存在直接解法。
- 星塔霜息将两张暮色游侠换为星火连弹、两张霜环换为双生星使。减少纯拖延，增加可持续的场面反击与结束比赛的手段；霜环仍可用于自组或轮抽。

玩家保存的自组卡组不被预组调整覆盖。已有牌局使用冻结的旧规则重演，避免旧录像因新数值失效。

## 对照结果

600 场交叉对局：6 套预组两两对战，每组使用 20 个种子，互换两边座位，共 40 场；每套卡组参与 200 场。双方使用挑战档规则 AI，以便与此前诊断的同组种子比较。下表胜率为胜场除以全部场次，平局计入分母。

| 卡组 | 调整前胜率 | 调整后胜率 | 调整后胜 负 平 |
| --- | ---: | ---: | ---: |
| 工坊零件潮 | 58% | 51% | 102／98／0 |
| 工坊重装 | 31.5% | 47.5% | 95／105／0 |
| 林地共生 | 59% | 42.5% | 85／106／9 |
| 林地萌芽 | 48% | 51.5% | 103／97／0 |
| 星塔连奏 | 44.5% | 47% | 94／106／0 |
| 星塔霜息 | 53.5% | 56% | 112／79／9 |

原先林地共生对星塔霜息是 **30 胜、4 负、6 平**，本轮为 **15 胜、16 负、9 平**。15 组交叉组合中，最高单方胜场为 27／40；原先最极端的一组已减弱，但共生与霜息的慢局和平局仍值得继续观察。

240 场同卡组对照：每套卡组使用 40 个种子。调整前先手 151 胜、后手 50 胜、39 平；本轮先手 **113 胜、后手 91 胜、36 平**。排除平局，先手胜率从约 75.1% 降到约 55.4%，仍有先手优势。

240 场难度对照：以标准档作为固定基准，六套同卡组分别对练习和挑战，互换座位，每档 120 场。基准对练习为 **58 胜、44 负、18 平**；对挑战为 **32 胜、71 负、17 平**。这说明练习档相对更容易，不代表真人玩家的预期胜率。

这些种子用于本轮调参和回归比较，并非独立盲测。规则自对战能发现明显数值与机制问题，不能代替真人体验或证明所有自组卡组都已平衡。

## 验证范围

65 项规则检查通过，覆盖水晶发放与能量上限、三档合法决策、八人完整联赛、棋池守恒、升星装备归并、备战席容量、经济、站位、成对结算和完整重演。36 份此前牌局与棋阵回放通过历史终态校验。

实际浏览器覆盖四向球拍操作、蛇的连续转向与吃食物动效、棋阵招募布阵、野怪装备、商店锁定、棋手对战、保存恢复、查看对手、触控落子、离线入口，以及牌局法术动画、电脑拖拽、手机操作和两个独立卡牌好友客户端。未把浏览器自动检查等同于真人试玩。

可用 `npm test`、`npm run check:round3` 和 `npm run bench:round3` 复现相应检查。浏览器检查前启动本地服务；`ARENA_URL` 指定试玩地址，`ARENA_RESULTS` 指定输出目录。当前新格式为 `glimmer-3`，旧牌局与二人棋阵继续按其历史格式读取。
