## 存档与玩家隔离

GitHub Pages 展示版的单人游戏在浏览器运行。存档写入网站的本地存储，没有服务器上的公共对局，也没有账号同步。

- 相同浏览器个人资料访问相同网站：可读到先前的存档和纪录。
- 换浏览器、换设备、换浏览器个人资料或使用无痕窗口：拥有独立进度。
- 清除该网站数据会删除本地存档。相同浏览器多个标签页共用存储，后保存的结果可能覆盖前一个标签页。
- 贪吃蛇、乒乓、牌局、棋阵、救援保留可恢复局面；赛车、音游和跑酷保留最好成绩与相关偏好，在页面内切换会暂停，刷新后当前比赛重新开始。
- 导出的文件是可校验的对局录像，不是账号云存档或全部进度迁移。

## 音乐与操作

新版舞台继续使用两首原创合成曲《晚风起舞》（96 BPM）与《末班电车》（120 BPM）。旋律发声与谱面来自同一份编排；入门保留主要节拍，挑战加入更多细分节拍，均包含长按与双键。玩家只需在音符头到亮线时按下对应轨道，长条保持到尾部。

音符使用音频时钟推进，暂停冻结音乐与判定；长按中暂停，继续后有 180 毫秒重新接住按键。支持调落速、节拍校准和静音练习。旧方向舞步录像仍可载入，旧版分数与新版分数使用不同纪录键。

触屏可以直接点整条音轨，多根手指不会互相释放对方的按键。赛车不再要求手机玩家一直占用一根手指踩油门，自动油门下仍可主动刹车。跑酷默认自动向前跑，既能滑动，也能点屏幕按钮。

## 跑酷规则与范围

左右滑动换道，上滑跳跃，下滑翻滚；跳跃中可以换道，下滑会提前落地。双击画面或按空格启用护板，持续 10 秒，抵挡一次碰撞后破碎并给予短暂保护。初始有一块护板，途中可以拾取更多。

低路障可以跳过，横梁需要翻滚，缺口可以跳过，列车需要换道。磁铁持续 10 秒，可吸引相邻路线的金币。每段障碍至少保留一条无障碍路线；舒缓和挑战分别从较慢、较快的速度起跑，随后逐步加速。得分为行进距离加金币奖励，碰撞后展示具体原因与本地纪录。

这是原创画面的核心玩法首版，目前没有地铁跑酷完整的角色商店、任务系统、喷气背包、列车顶部路线、赛事或联网排行榜。现阶段跑酷是单人挑战本地纪录；舞台和赛车仍有浏览器内的规则对手。

## 验证

- `npm test`：133 项通过，包含旧七款规则与录像、新音游整曲一致性、双键与长按、跑酷障碍动作、护板、磁铁及可行路线检查。
- `npm run check:motion`：真实音频时钟下命中音符；浏览器触屏事件验证双指和弦、暂停续接长按、转向加漂移、触摸取消、跑酷四向滑动与双击；整曲、碰撞结算、录像、旧舞台录像兼容和浏览器之间的存储隔离通过。
- 三款动作游戏检查 1366×768、1280×640、390×844、375×667、320×568、844×390，共 18 个界面组合；屏幕内包含游戏画面与操作区。
- `npm run check:polish`：原有五款的切换与进度恢复、卡牌交互和末次伤害、棋阵购买布阵结算、救援三关、手机尺寸和静态子路径通过。
- 八款离线页面均可切换；运行没有新的浏览器脚本错误。

上述触屏检查使用浏览器的触摸事件与移动视口。尚未在实体 iPhone、Android 平板或蓝牙耳机上测量手感和音频延迟，不能据此保证所有设备都同样流畅。

复测：先构建并启动本地预览，再设置 `ARENA_URL` 指向预览地址。浏览器验收结果默认保存在仓库旁的 `output/game-agent-lab/rhythm-runner-2026-11-19/`，不随源码上传。
