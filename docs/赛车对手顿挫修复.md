# 赛车对手顿挫修复

> 发布策略已更新：线上只保留当前试玩入口，本文提及的历史试玩、试验页和对照页已撤下。历史实现保留在源码分支中；以下内容为当时的开发记录。

日期：2026-11-19。分支：`fix/kart-smooth-opponents-2026-11-19`。

## 原因与改动

对手的模拟位置每秒更新 60 次，但画面将车辆吸附到最近的路面分段端点，每段相距 24 个世界单位。车辆在同一段内前进时，显示位置和大小不变；跨段后突然跳到下一个端点。这会产生明显的走走停停感。

现在使用车辆的实际距离计算透视位置和大小，弯道横向位置也连续计算。同时修复摄像机越过路面分段时的弯道衔接，并在相邻模拟状态之间平滑绘制，使 120／144 Hz 等刷新节奏也能连续呈现运动。

暂停、切换游戏、重开与录像播放会重置绘制用的前一帧，避免恢复时倒跳。显示平滑不写回对局状态，赛车速度、碰撞、AI 决策与录像规则保持兼容。

## 复现与检查

复现条件：晴湾环岛、练习对手、默认种子，玩家停车，观察橘子车从后方经过并驶远；画布为 1366×510。

| 指标 | 修复前 | 修复后 |
| --- | --- | --- |
| 可见且带名字的采样帧 | 199 | 197 |
| 实际前进但显示纵向位置不动 | 175 帧 | 0 帧 |
| 相邻采样最大纵向位移 | 98.04 像素 | 5.26 像素 |

前后可见帧数略有差别，是名字的显示距离也改为使用实际深度。该结果证明特定场景中的分段跳动已消除，不代表所有设备的实际帧率。

- `npm test`：138 项通过。新增检查覆盖逐帧前进、两条赛道所有分段和换圈边界、60／120／144 Hz 的绘制节奏、绘制不改变模拟状态、重置与结算。
- `npm run check:kart-motion`：在浏览器中记录真实画布绘制位置，验证桌面与手机视口、60／120 Hz 模拟刷新节奏；检查暂停、切换回来、自动油门、多指漂移和取消触摸。
- 更新前的 `kart-1` 录像保留为回归样例，确认可原样校验、播放并重新观看。

本地验证：运行 `npm run build:pages`，用本地 HTTP 服务提供 `site/`，设置 `ARENA_URL` 后运行浏览器检查。结果默认输出到仓库旁的 `output/game-agent-lab/kart-smooth-2026-11-19/`。
