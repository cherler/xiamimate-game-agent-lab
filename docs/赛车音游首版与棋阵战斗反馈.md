## 核心玩法取舍

### 微光漂移

用车后视角的透视道路表现赛车，画面由 Canvas 绘制。晴湾环岛偏宽弯，云岭弯道偏连续弯。方向、速度、侧滑与当前弯度共同决定横向位置，按住油门不能自动通过整条赛道。

- `↑ / W` 油门，`↓ / S` 刹车，`← → / A D` 转向。
- 过弯时配合方向按住 Shift；有速度、在路面内且弯向正确才积攒漂移。松开漂移触发小喷，并把积攒量转为氮气。直线反复左右摆动不能刷气。
- 空格使用氮气，最多存两管。撞墙和车辆接触会损失速度。
- 手机可同时按油门、方向与漂移。规则车手使用同一速度、碰撞与漂移规则，会提前看弯和避让前车；练习档目标速度较低。
- 两圈后按完赛先后排名；180 秒未到终点记为未完赛。

首版未做道具赛、真实三维车辆物理、多人联机与成长经济。先验证转向、漂移、超车是否有乐趣，再决定增加弯道类型、追赶道具和赛季挑战。

### 微光舞台

采用经典方向序列玩法：先从左到右输入箭头，看到光点来到第四拍圆环时按空格。箭头正确会逐个亮起，输错会重置当前序列；没有完成序列、太早或太晚确认均会 Miss，每组只能结算一次。

- 《晚风起舞》96 BPM、20 组舞步；《末班电车》120 BPM、24 组舞步。音乐用 Web Audio 原创合成，第一次点击“开始对舞 · 开启音乐”才启动。
- 入门 3–5 键，挑战 4–7 键；方向键和 WASD 均可用，也可点屏幕方向与踩拍按钮。
- 判定窗口：±55 ms 为 Perfect，±110 ms 为 Great，±180 ms 为 Good，之外或不完整为 Miss。
- 采用音频时钟计算判定，画面跟随同一个时钟；提供 ±150 ms 手动节拍校准。暂停时停止发声和计时，静音后继续游戏仍保留静音。
- 同场规则舞伴具有固定种子下可复现的偏差与漏拍，不是每拍完美。结算展示分数、准确率、各档次数和最长连击。

首版未做授权流行曲库、自由舞八键、双人情侣模式、服装经济或公网匹配。当前舞步是递增长度的四方向序列；后续应先验证判定手感，再增加人工编排的谱面和更细的舞蹈动作。

### 画面方向

赛车采用晴空蓝、海湾绿、暖黄车身、珊瑚路肩和蓝灰路面；宽阔道路作为主画面，排名、圈数、速度和集气依附在画面边缘。舞台采用靛蓝背景、薄荷与蜜桃色双人角色，底部保留方向序列、节拍环和触屏控制。两款沿用对练场字体与导航，各自把可操作画面放在一屏内，不增加说明文档式侧栏。

## 验证

规则检查共 121 项通过，新增 8 项覆盖加速／刹车／碰撞、漂移资源约束、两赛道两难度完赛、确定性回放、四拍判定与重复输入防刷分、校准和棋阵越线接敌。两赛道的规则驾驶均可在 100 秒内完成两圈，棋阵战斗不会改写部署位置。

`npm run check:motion` 验证：

- 真正的键盘油门与暂停、换赛道；完整赛车录像播放到冲线和重开。
- 真实音频时钟下输入方向并踩拍得分，暂停冻结、静音续播、回放校验；另外使用受控时钟检查整曲结算与重新开始。
- 1440×900、1366×768、1280×640、390×844、375×667、320×568、844×390 中相应的桌面／手机／横屏场景无页面溢出，画面与操作在同一屏内。
- 手机方向触屏输入、双指油门加转向、七款游戏离线切换。浏览器检查未报告页面脚本错误。

原五款 `check:polish`、棋阵 `check:chess-screen` 也通过，覆盖旧存档、牌局结算、救援三关、商店、装备、跨轮、回放、矮屏和手机布局。另实测战斗中点选棋子的范围反馈与手动布阵禁用状态。

本地截图和录像结果放在 `output/game-agent-lab/kart-dance-2026-11-19/`，不随源码仓库提交。验证用于确认机制、交互与兼容性；音乐音色、漂移难度和舞步节奏仍需要玩家实际试玩反馈。
